【 PROBLEMS FIXED 】

1. ❌ Weight exceeding 100% 
   └─ Trips were exceeding max weight limits (e.g., 104% utilization)
   └─ Cause: Old greedy 2-group split could leave group 2 still overweight

2. ❌ Trip order mixed up
   └─ When exporting Excel, trip sequence was not optimal
   └─ Cause: Trip assignment logic needed correction with bin-packing

3. ❌ Fill first trip completely
   └─ Needed to maximize utilization by filling first trip before moving to next
   └─ Cause: Greedy split didn't optimize trip packing

【 SOLUTION: FFD BIN-PACKING ALGORITHM 】

Replaced old greedy 2-group split with First-Fit Decreasing (FFD) bin-packing:

Algorithm:
  1. Identify trips exceeding weight/cube limits
  2. For each overweight trip:
     a. Sort branches by weight (descending) 
     b. Add branches to current trip while under limit
     c. When adding next branch would exceed limit → create new trip
     d. Continue until all branches assigned
  3. Apply new trip assignments to dataframe
  4. Trips get renumbered and sorted before export
